#´[Site da IoT](https://olima33.github.io/Site_da_IoT/)

Projeto web desenvolvido com o objetivo de apresentar conceitos relacionados à Internet das Coisas (IoT), além de servir como base prática para estudo de desenvolvimento web (HTML, CSS e JavaScript).

## Sobre o projeto

O Site da IoT é uma aplicação web estática que reúne informações sobre o curso técnico de Internet das Coisas, incluindo:

* Conceitos básicos da área
* Exemplos de projetos
* Estrutura do curso
* Formulários de interação (login, dúvidas, etc.)

O projeto foi desenvolvido com foco educacional, buscando praticar a construção de interfaces, organização de layout e estruturação de páginas web.

## Funcionalidades

* Navegação entre páginas (Início, Login, Projetos, etc.)
* Layout com uso de Flexbox
* Formulários de entrada de dados (login e dúvidas)
* Organização visual com componentes reutilizáveis (box, box2)
* Estilização com CSS

## Tecnologias utilizadas

* HTML5 — estrutura das páginas
* CSS3 — estilização e layout
* JavaScript — validações básicas e interatividade

## Estrutura do projeto

Site_da_IoT/

* html/ — Estrutura das páginas
* ../materias/ — Matérias técnicas do curso
* css/ — Estilos do site
* js/ — Scripts JavaScript
* static/ — Imagens e arquivos

## Objetivo

* Praticar desenvolvimento front-end
* Entender organização de código em múltiplas páginas
* Criar base para projetos maiores
* Evoluir para aplicações mais completas
